1. What is an AI agent?
2. Name two multi-agent frameworks.
3. Which agent checks facts in our pipeline?
4. What is a hallucination?
5. Why compare with a single-prompt result?
6. What does "sandboxed" mean for agents?
7. What is an agent loop failure?
8. Why must humans review AI outputs?
9. Name two official sources for CrewAI/AutoGen information.
10. What does Process.sequential do in CrewAI?

# Answer Key
1. A model-driven program that plans, uses tools and acts toward a goal.
2. CrewAI, AutoGen.
3. Reviewer.
4. Confident but false or unsupported output.
5. To measure whether multiple agents actually improve accuracy.
6. Running with restricted access, no private accounts or sensitive data.
7. Agents repeat steps or hand work back and forth without progress.
8. AI can be wrong, outdated or unsafe.
9. docs.crewai.com, microsoft.github.io/autogen.
10. Tasks run one after another, each passing output to the next.
