# Prompt Library
## Researcher
"You are a researcher. Give 8 facts about {topic} with source names. Mark uncertain items UNVERIFIED."
## Writer
"Using ONLY these notes: {notes}, write a 300-word summary for CSE students. Add no new claims."
## Reviewer
"Fact-check this draft: {draft}. List wrong, unsupported, outdated or unsafe claims, then give a corrected version."
## Single-prompt baseline
"Write a 300-word research summary on {topic} for CSE students. Mention sources."
## Hallucination test
"List 3 claims in this text that you cannot verify, and say why."
